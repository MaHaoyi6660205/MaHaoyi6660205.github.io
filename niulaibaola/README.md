# 牛来豹拉大冒险

一款纯前端、零依赖的网页动作冒险游戏。**牛来**近战冲锋、**豹拉**远程压制，用 `Tab` 随时切换操控，另一名角色由 AI 接管协同作战。10 大关卡 × 冒险场/精英场，第 5 关遭遇小 Boss 狼王，第 10 关迎战大 Boss 老虎，每场战斗后三选一强化，用基因点永久改造基因。

全部代码由原生 HTML / CSS / JavaScript 编写，Canvas 2D 渲染，无需构建、无需 npm，直接丢到 GitHub Pages 就能玩。

---

## 快速开始

### 本地试玩

两种方式任选：

1. **直接双击** `index.html`（无需服务器，即可运行）
2. **起个本地服务**（推荐，行为与线上一致）：

```bash
cd niu-lai-bao-la
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

### 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（例如 `niu-lai-bao-la`），勾选 Public。
2. 把本目录下的所有文件推送到仓库的 `main` 分支（保持目录结构不变）：

```bash
git init
git add .
git commit -m "牛来豹拉大冒险 首个版本"
git branch -M main
git remote add origin https://github.com/<你的用户名>/niu-lai-bao-la.git
git push -u origin main
```

3. 进入仓库 **Settings → Pages**，Source 选择 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，点击 Save。
4. 等待 1–2 分钟，访问 `https://<你的用户名>.github.io/niu-lai-bao-la/` 即可开玩。

> 仓库里已附带 `.nojekyll`，避免 GitHub 的 Jekyll 处理影响静态资源。  
> 若把游戏放在仓库根目录且仓库名为 `<用户名>.github.io`，访问地址就是 `https://<用户名>.github.io/`。

## 玩法说明

### 操作

| 按键 | 作用 |
| --- | --- |
| `WASD` / 方向键 | 移动当前操控的角色 |
| `J` / 鼠标左键 | 普通攻击（牛来横扫近战，豹拉发射爪刃） |
| `K` / 鼠标右键 / `Shift` | 角色技能（牛来蛮牛冲撞，豹拉疾风连射） |
| `Tab` / `1` / `2` | 切换操控角色，另一名角色交给 AI |
| 靠近倒地队友 | 自动救援（站到旁边读条，无需按键） |
| `Esc` / `P` | 暂停 / 继续 |

### 角色

- **牛来**：近战坦克。血量高、自带减伤，横扫攻击范围大，技能「蛮牛冲撞」可撞开敌群并造成眩晕。
- **豹拉**：远程输出。射速快、暴击高，技能「疾风连射」短时间内大幅提升射速并附带穿透。

### 关卡与战场

- 共 **10 关**，每关都有 **冒险场** 与 **精英场** 两个战场，任选其一通关即可推进主线。
- **精英场**：敌人更多更强，基因点奖励 ×2.5，通关额外获得一次强化机会。
- 小怪为**狼**（含精英狼），**第 5 关** 出现小 Boss **狼王**，**第 10 关** 出现大 Boss **老虎**（三阶段，会狂暴与召唤随从）。
- 每个 Boss 血量下降到一定比例会进入新阶段，招式更凶，同时掉落补给。

### 成长系统

1. **强化三选一**：每场战斗胜利后从三张强化卡中选一项，永久生效（牛来专属 / 豹拉专属 / 全队通用 / 队伍协同四类）。
2. **基因点**：击败敌人掉落基因碎片，通关结算大量发放；失败也会保留一半，所以卡关时反复挑战同样能变强。
3. **基因实验室**：消耗基因点购买永久属性（体质 / 力量 / 敏捷 / 专注 / 幸运 / 贪婪 / 战前护盾），价格随等级递增。

### 倒地与救援

角色血量归零不会直接死亡，而是**倒地**等待救援；队友靠近读条即可扶起（恢复 45% 生命）。两人同时倒地才算战斗失败。强化「不屈意志」可让倒地角色自行站起一次。

## 目录结构

```
niu-lai-bao-la/
├── index.html          # 页面骨架 + 全部 UI 面板
├── css/style.css       # 界面样式（HUD、菜单、卡片）
└── js/
    ├── utils.js        # 数学/随机/输入/音效合成/摄像机/粒子
    ├── config.js       # 数值配置、10 关数据、强化池、基因实验室
    ├── entities.js     # 玩家、敌人、Boss、弹道、掉落物与角色绘制
    ├── ai.js           # 队友 AI（走位、输出、救援、躲避）
    ├── world.js        # 场景地形绘制与波次调度
    ├── game.js         # 主控：状态机、战斗循环、存档、界面联动
    └── main.js         # 启动入口
└── test/               # 无头测试脚本（可选，部署时可删）
    ├── headless.js     # 冒烟测试：全流程无异常
    ├── debug.js        # 伤害链路诊断
    └── progression.js  # 10 关难度曲线模拟
```

## 想改数值？

全部集中在 `js/config.js`：

- `CONFIG.BASE`：两名角色的基础属性（血量、移速、攻速、伤害、技能冷却等）
- `CONFIG.ENEMY`：狼 / 精英狼 / 狼王 / 老虎的基础属性
- `CONFIG.SCALE`：关卡成长系数
- `CONFIG.ELITE`：精英场强度倍率
- `UPGRADES`：强化卡池（`apply` 里写效果，`max` 控制可叠加次数）
- `SHOP`：基因实验室条目与价格

改完刷新页面即可生效，无需构建。

## 浏览器支持

Chrome / Edge / Firefox / Safari 的现代版本均可；推荐使用桌面端浏览器与键盘鼠标操作。进度保存在浏览器 `localStorage`，换浏览器或清理缓存会清空存档。
